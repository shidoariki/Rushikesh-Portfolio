## 🚀 How to View Your Portfolio Website

1. Open File Explorer to `d:\tt1`.
2. Double-click **`index.html`** to view your portfolio in Chrome, Edge, or Brave.
3. Test the **Live Analytics Playground** by clicking the scenario tabs to see the live SQL query, DAX calculations, and resulting data tables update in real time.
4. Try toggling between **Dark Mode** and **Light Mode** using the sun/moon icon in the top navigation bar.

## ☁️ How to Deploy Online for Free (GitHub Pages)

1. Create a public repository on GitHub named `rushikeshpatil-portfolio`.
2. Push all the files in `d:\tt1` to the repository:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio release"
   git branch -M main
   git remote add origin https://github.com/<your-username>/rushikeshpatil-portfolio.git
   git push -u origin main
   ```
3. In GitHub, go to **Settings** > **Pages** > select **main branch** as source and click **Save**.
4. Your website will be live in 1 minute at `https://<your-username>.github.io/rushikeshpatil-portfolio/`!

## 📄 How to Export Resume to PDF (1-Page Strict Fit)

1. Open [`Rushikesh_Patil_Resume.html`](./Rushikesh_Patil_Resume.html) in your browser.
2. Click **"Print / Save as PDF"** (or press `Ctrl + P`).
3. Set **Destination** to `Save as PDF`, **Paper Size** to `A4`, and enable **Background graphics**.
4. Save as `Rushikesh_Patil_Resume.pdf`.
